# Gammanite multilingual update

This package contains the complete updated public folder, including British English, Traditional Chinese and Japanese pages and two new atmospheric images.

1. Extract the ZIP on your computer. Do not upload the ZIP itself.
2. In GitHub, open gammanite/gammanite-website, then open gammanite-website-v1-2.
3. Choose Add file > Upload files and drag the extracted public folder into the upload area. The files should appear under public/, not public/public/.
4. Review and commit. Keep Cloudflare's existing root directory unchanged.
5. After the deployment succeeds, check gammanite.com, gammanite.com/zh/ and gammanite.com/ja/ on phone and desktop.

The brand names and the motto “Here further.” intentionally remain unchanged in every language. Translations are draft editorial translations; a native-language editorial review is recommended before wider promotion.

Validation: local file references and JSON-LD passed on all three pages. Git whitespace validation passed. Automated visual testing could not run because the local browser executable is unavailable. Deployment has not been performed.

Image direction: two generated companion landscapes matching the original misty lake image. Markets uses layered forest ridges and silver water in drizzle; Industries uses rain-wet stone and weathered timber at a foggy lakeshore. These are atmospheric illustrations, not documentary photographs of specific markets or company facilities.
